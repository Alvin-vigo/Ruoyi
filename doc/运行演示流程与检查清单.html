Spring Boot 后端 Vue2 前端 FastAPI AI 微服务 Ollama 大模型 MySQL + Redis

1系统架构与数据流

浏览器访问前端 8081，前端经 dev 代理把请求转发给后端 8080；后端把 AI 类请求再转给 FastAPI 8000；AI 服务调用本地 Ollama 11434 的大模型或本地训练的 sklearn / PyTorch 模型。登录态 token 存于 Redis(Memurai) 6379，业务数据存于 MySQL 3306。

蓝线：业务请求链路　绿线：AI 推理链路　橙线：数据/缓存依赖

3启动流程（两种方式）

A. 一键启动（推荐演示用）

双击项目根目录的 start.bat，脚本依次拉起 6 个服务，各服务在独立窗口运行。已内置 Ollama 启动步骤，无需手动起。

1
启动 MySQL
自动 net start MySQL80（失败回退 MySQL）；本机元数据库 ruoyi_medical。
2
启动 Redis（Memurai）
启动 D:\Memurai\memurai.exe，端口 6379，登录 token 存储于此。
3
启动后端
若已有 jar 直接 java -jar ruoyi-admin-1.0.0.jar --server.port=8080；否则先 mvnw clean install -DskipTests 再启动。
注意 强制 --server.port=8080 是为防止系统环境变量注入随机端口（实测曾出现 58600 / 57999 导致 404）。
4
启动前端
npm run dev，监听 :8081，含 dev 代理（已补齐 /login、/getInfo、/logout 转发）。
5
启动 AI 微服务
uvicorn main:app --port 8000，提供病历/风险/胸片/RAG 接口。
6
启动 Ollama
ollama.exe serve，:11434；首次需预拉模型（约 4.7GB，仅一次）：ollama pull qwen2.5:7b-instruct-q4_K_M。

6常见问题排查（演示救急）

现象原因 / 解决
