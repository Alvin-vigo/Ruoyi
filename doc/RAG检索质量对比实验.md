# RAG 检索质量对比实验（论文"实验章节"硬数据）

## 一、实验目的
验证"本地知识库检索增强（RAG）"相对"纯大模型直答"在**医学导诊场景**下的价值：
- 证明检索增强能**显著降低幻觉**（库外问题触发拒答，而非编造）；
- 证明回答**可溯源**（命中知识库时附带引用来源）；
- 为论文"系统评测"一节提供可复现、可截图的数据。

## 二、两种对比模式
| 模式 | 实现 | 模拟对象 |
| --- | --- | --- |
| A 纯大模型（无检索） | 直接把问题丢给 Ollama，不挂知识库 | "玩具"RAG / 未接入知识的聊天机器人 |
| B RAG（有检索） | 先检索 Chroma 向量库，命中 ≥ 阈值才拼进 prompt 交由大模型 | 本系统的真实导诊链路 |

> 设计要点：B 模式在**知识库未命中时直接拒答**（不交给大模型自由发挥），这是医学防幻觉的关键护栏。

## 三、运行步骤
1. 启动 Ollama 并拉取模型（首次）：
   ```bash
   D:/AI/Ollama/ollama.exe serve
   ollama pull qwen2.5:7b-instruct-q4_K_M
   ```
2. 确保知识库已构建（10 条 `medical_knowledge` 已导入 Chroma）：
   ```bash
   cd ruoyi-ai
   python scripts/build_rag_db.py
   ```
3. 运行对比脚本：
   ```bash
   cd ruoyi-ai
   python scripts/rag_compare.py
   ```
4. 脚本会在 `ruoyi-ai/scripts/rag_compare_result.md` 生成 Markdown 对比表，直接截图或复制到论文。

## 四、10 个典型问题设计
覆盖三类，便于体现差异：
- **库内可答**（挂号时间 / 医保报销 / 儿科挂号费 / 糖尿病症状 / 高血压饮食 / 感冒用药 / 胸片空腹 / HbA1c 解读 / 公众号预约）——验证命中 + 引用；
- **库外需拒答**（"猫打喷嚏看宠物医院"）——验证防幻觉拒答，纯大模型反而可能"一本正经胡说"。

## 五、结果解读与论文写法
- **定性结论**：RAG 模式在库内问题上回答更贴合规、且每条附引用；库外问题上 RAG 安全拒答，纯大模型易产生无依据建议（幻觉）。
- **定量建议**：记录两类问题各自的"命中率 / 拒答准确率 / 引用条数"，与基线（纯大模型）做对照表。
- **可复现性**：脚本与知识库均本地化（embedding 模型已离线），评审可当场复跑，避免"无法复现"质疑。
- **注意**：本实验为**离线对照**，非大模型自动评测（如 BLEU/ROUGE），论文中应如实说明这是"人工核验 + 对照"的评测方式，符合本科毕设体量。
