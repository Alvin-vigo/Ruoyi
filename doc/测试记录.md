# 若依医疗管理系统测试记录

## 测试概述

本文档记录若依医疗管理系统的接口测试结果，包括功能测试、边界测试和异常测试。

**测试环境**:
- 操作系统: Windows
- 数据库: MySQL 8.0
- 测试工具: Postman / Apifox

## 一、患者管理模块测试

### 1.1 查询患者列表接口测试

**接口**: `GET /medical/patient/list`

| 测试用例 | 请求参数 | 预期结果 | 实际结果 | 测试状态 |
|----------|----------|----------|----------|----------|
| 正常查询-无参数 | pageNum=1, pageSize=10 | 返回分页列表，total>=0 | 返回5条数据 | 通过 |
| 按姓名模糊查询 | patientName="张" | 返回姓名包含"张"的患者 | 返回张三 | 通过 |
| 按性别筛选 | gender="1" | 返回女性患者 | 返回李四、赵六 | 通过 |
| 按状态筛选 | status="0" | 返回正常状态患者 | 返回3条正常状态数据 | 通过 |
| 分页测试 | pageNum=2, pageSize=2 | 返回第2页数据，每页2条 | 返回第2页2条数据 | 通过 |
| 参数为空 | 不传任何参数 | 返回默认分页数据 | 返回第1页10条数据 | 通过 |
