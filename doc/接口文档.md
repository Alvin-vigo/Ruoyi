# 若依医疗管理系统接口文档

## 概述

本文档描述若依医疗管理系统后端提供的 RESTful API 接口，涵盖患者管理和诊疗信息两大模块。

**基础路径**: `http://localhost:8080`

**通用响应格式**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

**分页响应格式**:
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 100,
  "rows": []
}
```

---

## 一、患者管理接口

### 1.1 查询患者列表

- **URL**: `/medical/patient/list`
- **Method**: `GET`
- **描述**: 分页查询患者信息列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 当前页码，默认1 |
| pageSize | Integer | 否 | 每页条数，默认10 |
| patientName | String | 否 | 患者姓名（模糊查询） |
| gender | String | 否 | 性别（0男 1女 2未知） |
| phone | String | 否 | 联系电话（模糊查询） |
| idCard | String | 否 | 身份证号 |
| status | String | 否 | 状态（0正常 1住院 2出院 3死亡） |

**响应示例**:
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 5,
  "rows": [
    {
      "patientId": 1,
      "patientName": "张三",
      "gender": "0",
      "birthDate": "1990-05-15",
      "idCard": "110101199005151234",
      "phone": "13800138001",
      "address": "北京市朝阳区建国路88号",
      "bloodType": "A",
      "allergyHistory": "青霉素过敏",
      "status": "0",
      "createTime": "2024-01-15 09:30:00"
    }
  ]
}
```

---

### 1.2 查询患者详情

- **URL**: `/medical/patient/{patientId}`
- **Method**: `GET`
- **描述**: 根据患者ID查询详细信息

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| patientId | Long | 是 | 患者ID |

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "patientId": 1,
    "patientName": "张三",
    "gender": "0",
    "birthDate": "1990-05-15",
    "idCard": "110101199005151234",
    "phone": "13800138001",
    "address": "北京市朝阳区建国路88号",
    "bloodType": "A",
    "allergyHistory": "青霉素过敏",
    "status": "0"
  }
}
```

---

### 1.3 新增患者

- **URL**: `/medical/patient`
- **Method**: `POST`
- **描述**: 新增患者信息

**请求体**:
```json
{
  "patientName": "赵小明",
  "gender": "0",
  "birthDate": "1992-03-15",
  "idCard": "110101199203156789",
  "phone": "13912345678",
  "address": "北京市海淀区中关村大街99号",
  "bloodType": "O",
  "allergyHistory": "无",
  "status": "0",
  "remark": "新入院患者"
}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功"
}
```

---

### 1.4 修改患者

- **URL**: `/medical/patient`
- **Method**: `PUT`
- **描述**: 修改患者信息

**请求体**:
```json
{
  "patientId": 1,
  "patientName": "张三",
  "phone": "13900139000",
  "address": "北京市西城区新街口5号",
  "status": "1"
}
```

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功"
}
```

---

### 1.5 删除患者

- **URL**: `/medical/patient/{patientIds}`
- **Method**: `DELETE`
- **描述**: 批量删除患者信息

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| patientIds | Long[] | 是 | 患者ID数组，多个用逗号分隔 |

**示例**: `/medical/patient/1,2,3`

**响应示例**:
```json
{
  "code": 200,
  "msg": "操作成功"
}
```

## 二、诊疗信息接口

### 2.1 查询诊疗列表

- **URL**: `/medical/diagnosis/list`
- **Method**: `GET`
- **描述**: 分页查询诊疗信息列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 当前页码，默认1 |
| pageSize | Integer | 否 | 每页条数，默认10 |
| patientId | Long | 否 | 患者ID |
| patientName | String | 否 | 患者姓名（模糊查询） |
| department | String | 否 | 就诊科室 |
| doctorName | String | 否 | 主治医生（模糊查询） |
| status | String | 否 | 状态（0待就诊 1就诊中 2已完成） |
| beginVisitDate | String | 否 | 就诊开始日期 |
| endVisitDate | String | 否 | 就诊结束日期 |

**响应示例**:
```json
{
  "code": 200,
  "msg": "查询成功",
  "total": 5,
  "rows": [
    {
      "diagnosisId": 1,
      "patientId": 1,
      "patientName": "张三",
      "visitDate": "2024-01-15 09:30:00",
      "department": "内科",
      "doctorName": "李医生",
      "chiefComplaint": "发热、咳嗽3天",
      "diagnosisResult": "急性上呼吸道感染",
      "treatmentPlan": "口服感冒药，多饮水，注意休息",
      "cost": 150.00,
      "status": "2"
    }
  ]
}
```

## 三、状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 操作成功 |
| 500 | 操作失败/系统错误 |

## 四、错误码说明

| 场景 | 错误信息 |
|------|----------|
| 参数校验失败 | 返回具体校验错误信息 |
| 业务异常 | 返回业务错误描述 |
| 系统异常 | "系统繁忙，请稍后重试" |
