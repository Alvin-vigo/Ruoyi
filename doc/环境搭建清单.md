## 二、需你本机自行下载安装（系统软件，我无法替你装进本机）

| # | 软件 | 版本 | 推荐获取方式 | 安装后验证命令 |
|---|---|---|---|---|
| 1 | **JDK** | **8（1.8）** | 免费发行版，无需 Oracle 账号：<br>• Adoptium Temurin 8：https://adoptium.net/temurin/releases<br>• Amazon Corretto 8：https://docs.aws.amazon.com/corretto/ | `java -version`（显示 1.8.0_xxx） |
| 2 | **Maven** | **3.8.8**（3.6.3 / 3.9.x 均可） | https://maven.apache.org/download.cgi （下载 Binary zip，解压并配置 `MAVEN_HOME` + PATH） | `mvn -v` |
| 3 | **Node.js** | **16.x（推荐 16.20.2 LTS）** | https://nodejs.org/zh-cn/download/ （选 16 长期维护版） | `node -v`、`npm -v` |
| 4 | **MySQL** | **8.0.x（社区版）** | https://dev.mysql.com/downloads/mysql/ （或先装 MySQL Installer） | `mysql --version` |
| 5 | **Redis（服务端）** | 见下方要点 | 见下方要点 | `redis-server --version` |

> ⚠️ **Node 版本务必用 16，不要装 18+**：本项目前端基于 Vue CLI 4，Node 18/20 上会触发 `openssl legacy provider` 报错。
> ⚠️ **JDK 务必用 8**：本项目 `pom.xml` 编译目标为 `java.version=1.8`，装 11/17 会编译失败。

### Redis 服务端在 Windows 上的安装要点（三选一）
Redis 官方不提供 Windows 原生版，以下方式任选其一：
1. **WSL2（推荐，版本新最稳）**：在 WSL2 终端执行 `sudo apt update && sudo apt install redis-server`，启动 `redis-server`。Windows 下的后端连 `localhost:6379` 经 WSL2 转发可达。
2. **Memurai（Windows 原生，免费开发者版）**：https://www.memurai.com/ ，MSI 一键安装并自动注册为 Windows 服务。
3. **旧版 MSI（Redis 3.2 for Windows）**：https://github.com/microsoftarchive/redis/releases （版本较老，仅应急）。

> 无论哪种方式，确保 Redis 监听 `127.0.0.1:6379`（与 `application.yml` 的 `spring.redis` 配置一致）。`spring.redis.password` 当前为空，与配置一致即可。

## 三、启动步骤（严格按顺序）

### 1. 建库 + 导入 SQL
```sql
CREATE DATABASE `ry-vue` CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```
在 `ry-vue` 库下**按序**执行（顺序错会导致建表失败 / 任务插不进 / 菜单挂错父级）：
```
ry_20231130.sql        （若依基础表 + admin 种子账号，必须先）
→ medical_schema.sql    （患者/诊疗/药品 + 测试数据）
→ medical_followup.sql
→ medical_message.sql
→ quartz.sql            （QRTZ_* + sys_job / sys_job_log）
→ medical_menu.sql
→ medical_ai.sql        （AI 模块 4 表）
→ medical_ai_menu.sql   （AI 菜单）
→ medical_drug_menu.sql （药品菜单，若与 medical_menu 冲突请核对）
```

### 2. 后端编译与启动
- 核对 `ruoyi-admin/src/main/resources/application.yml`：
  - MySQL 用户名/密码（默认 `root` / `Aa*040908`，如你已改 MySQL 密码请保持 yml 与之**一致**）。
  - **Redis 必须可用**：`spring.redis.host=127.0.0.1`、`port=6379`，启动前确保 Redis 已运行。
- 编译（**本机第一次真正意义上的全量编译**）：
  ```bash
  mvn clean install -DskipTests
  ```
- 启动：用 IDE 运行 `RuoYiApplication`，或 `java -jar ruoyi-admin/target/ruoyi-admin.jar`。
- ⚠️ 登录接口依赖 Redis：若 Redis 未启动，登录会报连接异常，请先启动 Redis。

### 3. 启动 Redis（本机，必须）
- WSL2：`redis-server`（后台运行）
- Memurai：服务已自启，或 `redis-server`
- 验证：`redis-cli ping` 返回 `PONG`

### 4. 前端安装依赖并启动
```bash
cd ruoyi-ui
npm install      # 首次会拉取依赖，耗时几分钟
npm run dev      # 默认端口 8081，自动打开浏览器，请求按路径代理到后端 8080
```

### 5. 访问
浏览器打开 `http://localhost:8081` → 登录页输入账号 `admin` / 密码 `admin123` → 进入首页。左侧菜单可见全部业务模块。

## 五、风险与未实跑项（如实告知）

1. **沙箱无 JDK**：后端从未在本环境编译，`mvn clean install` 是你本机第一次真编译。若报依赖缺失/版本冲突，把报错贴回即可。
2. **沙箱无 Node**：前端 `npm install` / `npm run dev` 未实跑。静态校验（引用路径、语法、标签）已全过，但运行时表现（el-menu 交互、业务页与后端联调、导出下载参数序列化）需本机验证。
