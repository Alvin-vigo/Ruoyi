# 药品信息管理模块 — 部署说明（作业3：代码生成器实战）

> 基于 RuoYi-Vue 代码生成器（Velocity 模板）生成的前后端完整模块，兼容 RuoYi-Vue，可直接导入运行。

## 一、模块概览

| 项目 | 内容 |
|------|------|
| 业务表 | `medical_drug`（药品信息表） |
| 生成实体 | `MedicalDrug`（com.ruoyi.system.domain） |
| 权限前缀 | `medical:drug:*`（list / query / add / edit / remove / export） |
| 后端接口 | `/medical/drug`（list 分页查询、{drugId} 详情、POST 新增、PUT 修改、DELETE 批量删除、export 导出 Excel） |
| 前端页面 | `ruoyi-ui/src/views/medical/drug/index.vue`（组件 `medical/drug/index`） |
| 前端 API | `ruoyi-ui/src/api/medical/drug.js` |

**功能清单**：增删改查、分页查询（PageHelper）、条件查询（药品名称模糊、药品分类/状态精确、生产厂家模糊）、Excel 导出（@Excel 注解 + ExcelUtil）、菜单权限（1 个 C 类型菜单 + 5 个 F 类型按钮权限）。

## 二、包结构

```
codegen/medical_drug/
├── sql/
│   ├── medical_drug_schema.sql      # 建表 + 测试数据
│   └── medical_drug_menu.sql        # 菜单 + 按钮权限
├── java/com/ruoyi/system/
│   ├── domain/MedicalDrug.java          # 实体（@Excel 导出注解、JSR-303 校验）
│   ├── mapper/MedicalDrugMapper.java    # Mapper 接口
│   ├── service/IMedicalDrugService.java # Service 接口
│   └── service/impl/MedicalDrugServiceImpl.java
├── java/com/ruoyi/controller/DrugController.java  # REST 控制器（含导出）
├── resources/mapper/MedicalDrugMapper.xml         # MyBatis 映射
└── vue/src/
    ├── api/medical/drug.js                        # Axios 接口封装
    └── views/medical/drug/index.vue               # 列表页（增删改查/分页/导出）
```

> 本包内文件与项目 `ruoyi-system` / `ruoyi-admin` / `ruoyi-ui` 中已集成的文件完全一致，已随项目编译通过。

## 三、环境要求

- JDK 1.8+、Maven 3.6+、MySQL 5.7+ / 8.0、Node.js 12+（前端）
- RuoYi-Vue v3.8.7 兼容（sys_menu 使用 path/component/is_frame/is_cache 字段结构）

## 四、部署步骤

### 1. 初始化数据库

```sql
CREATE DATABASE IF NOT EXISTS `ry-vue` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE `ry-vue`;
```

按顺序导入 SQL（任选 Navicat 或命令行 `mysql -uroot -p ry-vue < xxx.sql`）：

1. `sql/ry_20231130.sql` — RuoYi 基础表（含 admin/admin123 账号）
2. `sql/quartz.sql` — 定时任务表
3. `sql/medical_schema.sql` — 患者表、诊疗表、代码生成器业务表
4. `sql/medical_menu.sql` — 医疗管理目录 + 患者/诊疗菜单
5. `sql/medical_drug_schema.sql` — **药品信息表 + 测试数据（本次生成）**
6. `sql/medical_drug_menu.sql` — **药品信息菜单权限（本次生成，自动挂载到"医疗管理"目录下）**

### 2. 修改后端配置

`ruoyi-admin/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
    username: root
    password: ${DB_PASSWORD}   # 由 .env 注入，勿在配置或文档中写死
```

> 当前项目已配置为 `ruoyi_medical` 库；数据库口令通过 compose 同级的 `.env` 中 `DB_PASSWORD` 注入（模板见仓库根目录 `.env.example`）；若你使用 `ry-vue` 库名，同步修改 url 中的库名即可。

### 3. 编译并启动后端

```bash
mvn clean install -DskipTests
# 启动（任选其一）
mvn -pl ruoyi-admin spring-boot:run
java -jar ruoyi-admin/target/ruoyi-admin-1.0.0.jar
```

后端默认端口 **8080**。本次生成代码已通过 `mvn clean install` 全模块编译验证（BUILD SUCCESS、无报错）。

### 4. 启动前端

```bash
cd ruoyi-ui
npm install
npm run dev
```

浏览器访问 `http://localhost`（前端开发端口见 vue.config.js），使用 `admin / admin123` 登录。

### 5. 验收清单

- [ ] 左侧菜单出现【医疗管理 → 药品信息】
- [ ] 列表页展示 6 条测试药品数据，分页正常
- [ ] 按"药品名称/分类/生产厂家/状态"条件查询正常
- [ ] 新增、修改、删除（含批量）正常

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 菜单不显示 | 确认 `medical_drug_menu.sql` 已执行；admin 为超管不受权限限制，其他角色需在【系统管理-角色管理】分配菜单权限后重新登录 |
| 导出 404 | 确认访问路径为 `/medical/drug/export`，且控制器已在 ruoyi-admin 模块内 |
| 前端页面空白 | 确认 `index.vue` 位于 `ruoyi-ui/src/views/medical/drug/`，菜单 component 值为 `medical/drug/index` |
| 表已存在 | 脚本自带 `DROP TABLE IF EXISTS`，重复执行会清空重建 |

## 六、代码生成器使用说明（原理呼应）

本模块即按代码生成器标准产出：`medical_drug` 建表后在【系统工具-代码生成】导入，配置生成信息（模块名 `medical`、业务名 `drug`、功能名 `药品信息`、作者、生成包路径 `com.ruoyi.system`），即可通过 Velocity 模板（`ruoyi-generator/src/main/resources/vm/` 下的 domain/mapper/service/serviceImpl/controller/api.js/index.vue/sql 模板）一键生成上述全部代码——变量占位（`${tableName}`、`${ClassName}`、`${columns}` 循环等）与本项目模板一一对应。
